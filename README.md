# 🧮 **CALCULADORA PERSONALIZADA EM PYTHON (TKINTER)**

Uma calculadora simples com interface gráfica desenvolvida em **Python** utilizando a biblioteca **Tkinter**.  
O projeto possui layout personalizado, cores modernas e botões responsivos, proporcionando uma experiência visual agradável e intuitiva para o usuário.

---

# 🚀 **FUNCIONALIDADES**

- Operações básicas: adição (+), subtração (−), multiplicação (×) e divisão (÷)  
- Suporte a números decimais  
- Botão para limpar a operação (C)  
- Exibição de erro para expressões inválidas  
- Cálculo automático ao pressionar "="  

---

# 💻 **COM INTERFACE**

Aplicação desenvolvida com **Tkinter**, possuindo:

- Interface gráfica personalizada  
- Botões organizados em grade (layout responsivo)  
- Cores diferenciadas para números, operadores e botão de limpar  
- Campo de entrada estilizado e alinhado à direita
